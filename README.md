# Jaboscone Limited Kenya — Frontend Prototype

This is a responsive vanilla HTML/CSS/JavaScript frontend based on the Jaboscone Limited Kenya software requirements brief.

## Run it
Open `index.html` in a browser, or serve the folder with a local server.

Example:
- VS Code + Live Server
- `python -m http.server` from this folder

## Pages
- `index.html` — Home
- `services.html` — Services catalogue
- `products.html` — Cleaning products/e-commerce
- `booking.html` — Service booking flow
- `cart.html` — Cart
- `checkout.html` — Product checkout
- `login.html` — Demo customer login
- `dashboard.html` — Customer dashboard
- `admin.html` — Admin dashboard prototype
- `about.html` — About
- `contact.html` — Contact
- `faq.html` — FAQ

## Important
This release is frontend-only. Data is demo data and booking/cart actions use localStorage.

The next development stage is to connect these screens to:
- REST API / backend
- Authentication and role-based access
- Database
- M-Pesa/card payment provider
- Email/SMS/WhatsApp notifications
- Real admin CRUD and booking calendar

Official company contact details, logo, service pricing, product images, terms, privacy policy and final brand colours should replace the placeholders before production launch.
